# Beacon — public dashboard

The public, auto-generated dashboard for **Beacon**, a neutral, capability-normalized
price **reference rate for AI inference** ("what a unit of intelligence costs").

🔗 **Live:** https://zhijiewong.github.io/beacon-index/

- **`index.json`** — the public data feed (today's rates, per-tier prices, and chart series).
- Rates are capability-normalized on GPQA-Diamond and published daily.
- The reference rate is also posted **on-chain** (Base Sepolia) for any contract to read.

This repo holds only the built static site + data. The methodology and source live elsewhere.
